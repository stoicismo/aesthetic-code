# Code Art 

This project contains a small Python script where the code itself is written with an aesthetic layout. the logic is simple.

## Description

The script builds a 3x3 matrix using individually defined variables (A1 to C3).  
It then computes:

- Main diagonal sum
- Anti-diagonal sum
- Row sums
- Column sums

The output is printed using simple ASCII framing for clarity and visual structure.

## How to Run

Make sure you have Python installed, then run:

    python matrice.py

Example output:

|  MATRICE SIMMETRICA  |
+----------------------+
  |  1 |  2 |  3 |
